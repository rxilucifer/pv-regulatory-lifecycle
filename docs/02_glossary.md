Plain-language definitions of the terms used in this project. Regional terms and regulatory definitions must be checked against the current guideline before they are used in a regulatory-style document.

| Term | Meaning |
|---|---|
| Adverse event (AE) | Any untoward medical occurrence in a person given a medicine. It does not have to be caused by the medicine |
| Adverse reaction (ADR) | An adverse event where a causal link to the medicine is at least a reasonable possibility |
| Serious adverse event (SAE) | An adverse event that meets at least one seriousness criterion (see the style guide) |
| Expected (listed) | An event that is already described in the reference safety information or the label |
| Unexpected (unlisted) | An event that is not described there, or is more severe or more frequent than described |
| Individual case safety report (ICSR) | The report of one patient's suspected adverse event |
| Valid case | A report with the four minimum elements: an identifiable reporter, an identifiable patient, a suspect medicine and an adverse event |
| Causality assessment | A judgement about whether the medicine caused the event. This project uses the WHO-UMC categories |
| MedDRA | A licensed medical dictionary for coding adverse events. It is not used in this project, which uses a small made-up list instead |
| Preferred term (PT) | A single medical concept in MedDRA, such as a named symptom or diagnosis |
| Signal | Information about a possible link between a medicine and an event that needs further investigation |
| PRR, ROR, IC | Statistics that compare how often an event is reported for one medicine against others: the proportional reporting ratio, the reporting odds ratio and the information component |
| Benefit-risk evaluation | A judgement of whether the benefits of a medicine outweigh its risks |
| Reference safety information (RSI) | The list of events treated as expected for a medicine |
| Data lock point (DLP) | The date up to which data are included in a periodic report |
| Periodic safety report (PBRER or PSUR) | A report that reviews the safety of a medicine over a set period |
| Risk management plan (RMP) | A document that describes known and potential risks and how they are monitored and reduced |
| Product information | The label for health professionals and the leaflet for patients |
| Direct healthcare professional communication (DHPC) | A letter that tells health professionals about a new safety issue |
| Marketing authorisation holder (MAH) | The company that holds the licence to market a medicine |
| Common Technical Document (CTD) | The standard format for the dossier submitted to regulators |
| Variation | A change to a marketing authorisation. This is the European term, and the Indian term should be checked |
| GVP | Good pharmacovigilance practices, the European guidance on running pharmacovigilance |
| PvPI | The Pharmacovigilance Programme of India |
| CDSCO | The Central Drugs Standard Control Organisation, India's national regulator |
